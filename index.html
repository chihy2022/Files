Đẩy file lên GitHub

Cài đặt (làm một lần cho mỗi chế độ)

Repo Files để Public nên ai có link đều xem được. Đừng đưa tài liệu nhạy cảm vào đây, hãy dùng chế độ one-a và chọn PDF.
Chế độ này ghi vào repo one-a (trang đang chạy thật). Mỗi file đẩy lên sẽ làm Vercel deploy lại. PDF lưu trong server/files và được phân quyền. Video và ảnh lưu trong public nên ai có link đều xem được. Muốn thử trước, đổi Nhánh sang một nhánh thử (ví dụ test).
Cách tạo token
  1. Vào github.com → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: chọn Only select repositories rồi chọn đúng repo của chế độ đang dùng (mỗi chế độ một token riêng).
  3. Permissions → Repository permissions → Contents chọn Read and write.
  4. Bấm Generate token, copy và dán vào ô trên. Token chỉ hiện một lần.
Kéo thả file vào đây hoặc bấm để chọn
